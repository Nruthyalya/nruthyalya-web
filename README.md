# Nruthyalya website

- index.html: the site
- content/notes.json: notes, folders, YouTube links and gallery list (edit this to update the site)
- images/: photos used by notes and the gallery

Add a note: copy an entry in "notes", change title, folder (use / for sub folders), body, "images" (file names inside images/) and "links" (YouTube URLs). Keep the commas and quotes exactly as in the sample.

Notes added in the browser are saved only in that browser. Notes in notes.json show for everyone.
